# 내가 먹은 간식의 몸속 여행 — 연수 안내 웹페이지 (교사용)

중학교 과학 교사가 순서대로 읽고, 클릭하고, 프롬프트를 복사하며 따라 하는 **바이브코딩 연수 안내 사이트**입니다.
참가자는 이 안내를 보며 자신의 Google AI Studio·공공데이터포털·GitHub·Cloudflare 계정에서 중학생용 앱 「간식의 몸속 여행」을 만듭니다.

| 구분 | 이 저장소 (연수 안내) | 참가자가 만드는 앱 |
| --- | --- | --- |
| 색 | 청록 | 주황 |
| 형태 | React + Vite 정적 페이지 | React + Vite + Cloudflare Pages Functions |
| 인증키 | 받지 않음, 입력란 없음 | Cloudflare Secret `DATA_GO_KR_SERVICE_KEY` |
| 식품 API 호출 | 하지 않음 (미니 체험은 가상 데이터) | `/api/foods` 서버 함수가 호출 |

## 실행 방법

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 타입 검사 후 dist/ 생성
npm run preview    # 빌드 결과 미리보기 (http://localhost:4173)
```

Node.js 18 이상이 필요합니다.

## 정적 배포 설정

이 안내 사이트에는 서버 함수가 없으므로 어떤 정적 호스팅에도 `dist/` 폴더를 그대로 올리면 됩니다.

**Cloudflare Pages (GitHub 연결) 예시**

| 항목 | 값 |
| --- | --- |
| Framework preset | React (Vite) |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | 이 `package.json`이 있는 폴더 |
| 환경변수 | 없음 |

`vite.config.ts`의 `base: './'` 덕분에 하위 경로에 올려도 동작합니다.

> 참가자 앱의 Cloudflare Pages Functions 설정(`functions/api/foods.ts`, `health.ts`, `_routes.json`, Secret 등록)은 이 README가 아니라 **안내 본문의 7·9·11·12단계**에 있습니다. 참가자 앱은 정적 업로드가 아니라 GitHub 연결 배포로 Functions까지 배포해야 합니다.

## 구성

```
src/
  content/
    prompts.ts      참가자 프롬프트 01~10 전문 (복사 버튼이 그대로 복사)
    steps.ts        0~14단계 본문: 목표·작업 위치·따라 하기·복사 블록·확인 결과·체크리스트·문제 해결표·복구 프롬프트
    reference.ts    교육과정, 과학 내용 12가지, API 명세·정규화 정책, 가상 데이터, 강사 운영, 선택 확장, 공식 링크
    digestion.ts    미니 체험의 대표 소화 모형·효소 연결 설명 (교사가 문장 수정 가능)
  lib/
    nutrition.ts    가상 데이터 정규화·선택량 계산·접시 합계 (결측≠0, g/mL 비환산, 당류 비중복)
    storage.ts      버전이 있는 localStorage 저장, 차단 시 메모리로 계속 동작
    clipboard.ts    Clipboard API → execCommand → 수동 복사 대체
  components/       화면 컴포넌트
```

내용을 고칠 때는 `src/content/` 파일만 수정하면 됩니다.

## 안내 사이트 기능

- 상단: 제목, 핵심 질문, 준비 계정, 권장 시간(235분), 현재 단계, 전체 인쇄, 저장한 기록 지우기(확인 후), 움직임 줄이기. 진행률·완료율 집계는 두지 않는다.
- 「지금 보는 곳: 연수 안내 / 지금 작업할 곳: …」 표시.
- 왼쪽 0~14단계 목차, 모바일에서는 한 열과 접는 목차.
- 각 단계의 8개 요소: 목표·시간 / 작업할 서비스와 공식 링크 / 번호형 따라 하기 / 복사할 프롬프트·설정값 / 확인할 결과 / 완료 체크리스트 / 문제 해결표와 복구 프롬프트 / 이전·다음.
- 입력란은 「내 GitHub 저장소 주소」, 「내 완성 앱 주소」, 오류 메모뿐입니다. 인증키처럼 보이는 문자열을 붙이면 경고합니다.
- 14단계의 최종 확인 세 가지 「앱 화면 완성」, 「공개 배포 완료」, 「실제 공공 API 조회 확인」은 각자 직접 체크하는 개인 메모이며 집계하지 않습니다.
- 전체 인쇄: 모든 단계·프롬프트·설정표가 펼쳐지고 내비게이션과 복사 버튼은 숨겨집니다.
- 미니 체험: 연습용 간식 A~E(가상 데이터)로 기준량·결측값·접시 계산·대표 소화 모형·효소 연결을 확인합니다.

## 이미지 자료

- 목록·규격·생성 프롬프트의 원본은 `src/content/images.json` 한 파일입니다. 사이트의 「이미지 자료」 페이지와 `IMAGE_PROMPTS.md`(빌드 때 자동 생성, `npm run images:doc`로도 생성)가 모두 여기서 나옵니다.
- 만든 PNG는 `public/images/`에 목록의 파일 이름 그대로 넣고 다시 빌드·배포합니다. 파일이 없으면 사이트는 기본 그림(SVG)으로 대체하고, 「이미지 자료」 페이지에는 「아직 없음」으로 표시됩니다.
- 참가자는 「이미지 자료」 페이지에서 올라온 그림을 ZIP으로 내려받아(브라우저 안에서 묶음) 자기 저장소의 `public/images/`에 올린 뒤, 부록 프롬프트 A로 앱에 적용합니다. 부록 프롬프트 B는 이 사이트의 공개 주소를 직접 참조하는 대안입니다.
